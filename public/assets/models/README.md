# HerbiQ original 3D assets

Five computer-modeled educational illustrations: Tulsi, Neem, Aloe Vera, Turmeric, Ginger.

Each GLB contains real geometry, UVs, normals and embedded PNG textures with PBR materials. Models use metre-scale coordinates and a ground-level base. Leaf and branching structures differ per plant; these are not re-skinned copies of one generic model.

These are original procedural/computer-modeled illustrations, not photogrammetry scans, not photorealistic reproductions and not botanically validated identification material. The UI intentionally retains this disclosure. The files are suitable for interactive inspection and compatible-device AR experimentation; physical phone testing remains required.

Original generated assets and generator: CC0-1.0. The existing user-supplied plant photographs are not covered by this dedication. Third-party viewer/dependency licenses remain their respective licenses.

Rebuild from project root: `python scripts/build_models.py` (numpy, Pillow). Validate with `npm test`.
